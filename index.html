I.
The Question
p. 02

Ask a dealer principal what their gross profit was last month and they will ask you, reasonably, which one? Variable gross. Department gross. Front-end. Back-end. Total gross profit, line one—which is itself a definition that hides three more. The GM Standard Accounting Manual answers all of these. It just takes twenty minutes of flipping to find the answer for any one of them.

Robert runs four stores across two OEMs. Each month his controller sends him a statement that prints Variable Selling Expense 5.2 % of gross and Robert pages through five hundred PDFs to remember which gross. He doesn't want a chatbot. He wants the manual—the same manuals he already trusts—to answer in one breath and show him the page side-by-side so he can verify.

That is the entire product. Margin quotes the document or says nothing. It is named for both halves of what it does: the profit margin Robert watches every month, and the margin of the page where the citation lives.

“

I don't want it to guess. I want it to read.

— Robert, on a Tuesday
Hard rules, in order
  1. 01 If the manual doesn't say it, the copilot doesn't either.
  2. 02 Every answer cites a page. No page, no answer.
  3. 03 Quote verbatim before paraphrasing.
  4. 04 Refuse loudly when confidence is low. Refusal is a feature.
II.
A Three-Layer Pipeline
p. 03

Three stages, each with a single responsibility. Each is testable in isolation. Each refuses when it isn't sure—so the whole pipeline degrades to I don't know before it degrades to I made it up. The shapes have changed since the weekend; the rule has not.

01

Ingest · parse

User uploads a PDF in the Next.js sidebar. Pages are parsed client-side, then forwarded to the FastAPI service which chunks them into 3-sentence windows and POSTs to the user's index.

Input

Output
chunked pages, embedded
Boundary

02

Index · per-user

One Elasticsearch index per user—rag-<user>—with both BM25 (keyword mode) and a dense_vector field via sentence-transformers kNN (natural mode). Tenant isolation by construction.

03

Cite · verbatim

Search returns ranked verbatim quotes with doc + page + bbox; the UI opens the PDF side-by-side and highlights the cited region. When nothing scores, a Claude-CLI agent names which document type would unlock the query.

IV.
Colophon · The Stack
p. 05

Eight load-bearing dependencies in the live product. Each chosen because the alternative would require either rolling our own or paying a vendor for what is now a commodity.

  • 01 Next.js 14 Frontend · app router SSR + API routes in one process. Auth and PDF viewer co-located with the search UI.
  • 02 FastAPI Backend service Tiny surface — /ingest, /search, /documents, /health. Pydantic mirrors the frontend contract.
  • 03 Elasticsearch Per-user retrieval BM25 (keyword) + dense_vector kNN (natural) in one index per user. Tenant isolation by construction.
  • 04 sentence-transformers Embeddings + reranker Self-hosted, deterministic. No external embedding bill that scales with corpus.
  • 05 bcrypt + jose Auth · passwords + JWT cookie HTTP-only, SameSite=Lax. No third-party identity provider for a private prototype.
  • 06 claude-sonnet-4-6 Missing-doc agent (CLI subprocess) Reserved for refusals. Names the document type that would unlock a query the corpus can't answer.
  • 07 pdfplumber + pdf.js Server parse · client viewer Server extracts pages and bboxes; the browser renders the highlighted region side-by-side.
  • 08 Vitest + Playwright Tests Vitest for the auth and search-helper units; Playwright for the sign-in → upload → search → cite path.
