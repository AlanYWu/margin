# Dealer CFO Copilot — Marketing Site

Static landing page for the Dealer CFO Copilot project. Plain HTML / CSS / JS,
hosted on GitHub Pages.

**Live:** https://alanywu.github.io/dealer-cfo-copilot-site/

The product code lives in a separate (private) monorepo: `dealer-cfo-copilot`.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

Pushes to `main` are published automatically by GitHub Pages
(Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/` root).
